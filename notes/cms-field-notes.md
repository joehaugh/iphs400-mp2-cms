# Field notes

WordPress Playground observations, in my own words.

1. I thought the website editor was interesting but not as easy to use as expected.
2. It is great that you can be editing a site, but it is not active, even with the link, until you publish it or give someone editor access.
3. It was definitely my fault that I could not find the permalinks tab, but I eventually did.
4. The site names (URLs) become much longer than expected.
5. I think it is interesting that you can edit both visually and in the code itself.
